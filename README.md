# Mech-DLK SDK 3.0.0 Examples

Mech-DLK SDK 3.0.0 安装包自带的例程源码及工程文件，保留安装包中的原始目录结构和文件内容。

- `cpp/examples/`：基础推理、HALCON、OpenCV、多线程推理，以及原配 CMake 文件。
- `csharp/examples/`：基础推理，以及 `infer_with_halcon`、`infer_with_opencv`、`infer_with_ui`、`multi_thread_infer` 四个高级例程。
- `python/examples/`：基础推理、HALCON、OpenCV、多线程推理。

使用前请安装 Mech-DLK SDK 3.0.0，并按照配套文档配置 SDK 依赖和示例资源。HALCON、OpenCV 等依赖按对应工程要求配置。

本仓库收录 48 个安装包原配例程文件；SDK 运行库、头文件、链接库、Python 安装包、图像和模型使用配套安装包中的版本。各语言目录中的原配 README 一并保留。
